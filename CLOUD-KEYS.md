# Ключи облака — единый документ

**2026-08-22.** Один документ на всё облако. Здесь только то, что нужно
облачным прогонам: какие секреты, откуда берутся, что ломается без них.

## Как облако получает модели

Раннер **не достаёт** до прокси на Маке и никогда не достанет. Поэтому
`cloud-agent.yml` поднимает LiteLLM внутри задания из `cloud-config.yaml` —
семь ролей, 23 развёртывания, та же карта, что локально. Ключей в файле нет:
каждый заменён на `os.environ/<ПРОВАЙДЕР>_API_KEY`, значения приходят из
секретов репозитория.

Расчёты — корридорный замер, бисекция — **моделей не трогают вообще** и
работают без единого ключа.

## Секреты этого репозитория

| Секрет | Роли, которые от него зависят | Есть |
| --- | --- | --- |
| `NVIDIA_API_KEY` | act, architect, judge, coder | **да** |
| `GEMINI_API_KEY` | gemini | нет |
| `GROQ_API_KEY` | coder, cheap | нет |
| `MISTRAL_API_KEY` | plan, coder | нет |
| `OPENROUTER_API_KEY` | — | не нужен |
| `PLEXUS_CRYPTOCOMPARE_KEY` | — | больше не используется, маршрут перешёл на статический архив |

Провайдер без секрета даёт лань, которая падает и уходит в фолбэк. Прогон от
этого не встаёт, но роль работает хуже, чем на Маке.

**Vertex в облако не идёт намеренно:** он тратит платный кредит, а платная лань
за кнопкой, которую можно нажать с телефона, — отдельное решение, и оно не
принято.

## Откуда брать ключи для облака

**Не копировать локальные.** Квоты считаются по проекту, а не по месту вызова:
один и тот же ключ, вызванный из раннера и с Мака, тянет один потолок, и два
прокси друг о друге не знают — счётчики живут в памяти процесса. Копия даст не
вторую ёмкость, а двух оптимистов на одной квоте.

| Провайдер | Что завести под облако |
| --- | --- |
| Google | **отдельный проект** в AI Studio, ключ оттуда |
| Mistral | **отдельный workspace**, ключ оттуда |
| Groq | **отдельный аккаунт** — единственный способ, препятствий нет |
| NVIDIA | ничего: дневного потолка нет, делить нечего |

Подробности и цитаты — `docs/PROVIDER-ISOLATION.md` в проекте среды.

## Как класть

Settings → Secrets and variables → Actions → New repository secret. Значение
вводится в браузере и после сохранения не показывается никому, включая
владельца.

Проверить, что облако видит роли: Actions → `cloud-agent` → Run workflow. Шаг
«proxy with the real lanes» печатает список ролей, которые поднялись.
